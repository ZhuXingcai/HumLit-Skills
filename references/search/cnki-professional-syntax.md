# 知网专业检索表达式语法

> 依据知网官方检索手册 1.2.5。本文件只讲语法，检索策略见
> [知网高级检索：检索式构造与精准定位](./cnki-advanced-retrieval.md)。

## 一般式

```
<字段代码><匹配运算符><检索值>
```

## 1. 字段代码

| 代码 | 字段 | 代码 | 字段 |
|------|------|------|------|
| `SU` | 主题 | `AU` | 作者 |
| `TI` | 题名 | `FI` | 第一责任人 |
| `KY` | 关键词 | `RP` | 通讯作者 |
| `AB` | 摘要 | `AF` | 机构 |
| `FT` | 全文 | `JN` | 文献来源 |
| `RF` | 参考文献 | `YE` | 年 |
| `FU` | 基金 | `CLC` | 分类号 |
| `SN` | ISSN | `CN` | 统一刊号 |
| `IB` | ISBN | `CF` | 被引频次 |

## 2. 匹配运算符

同一个符号在不同字段中含义不同，这是最容易出错的地方。

| 形式 | 含义 | 适用字段 |
|------|------|---------|
| `= 'str'` | 与 str 相等 | `KY AU FI RP JN AF FU CLC SN CN IB CF` |
| `= 'str'` | 包含完整 str | `TI AB FT RF` |
| `% 'str'` | 包含完整 str | `KY AU FI RP JN FU` |
| `% 'str'` | 包含 str 及其分词 | `TI AB FT RF` |
| `%= 'str'` | 相关匹配 | `SU`（主题推荐用 `%=`） |

```
KY = 数据挖掘
AB % 计算机教学
SU %= 大数据
```

## 3. 逻辑运算符（字段之间）

`AND` / `OR` / `NOT`，**前后必须各有一个空格**；优先级用英文半角括号确定。

```
KY = 知识管理 AND AU = 邱均平
SU %= 知识管理 OR TKA = 知识管理
TI = 大数据 NOT TI = 大数据集
AU = 钱伟长 AND (AF = 清华大学 OR AF = 上海大学)
AU = 钱伟长 AND AF = 清华大学 AND (TI = 物理 OR AB = 物理)
```

## 4. 复合运算符（同一字段内部）

| 符号 | 含义 | 示例 |
|------|------|------|
| `*` | 并含 | `FT = 催化剂 * 反应率` |
| `+` | 或含 | `KY = 铝合金 + 钛合金` |
| `-` | 不含 | `KY = 大数据 - 人工智能` |

多个复合运算符可用 `()` 改变运算顺序。

## 5. 比较运算符

```
YE BETWEEN ('2010', '2018')
CF > 0
CF >= 1
```

## 6. 位置描述符（仅 `TI`、`AB`、`FT`；仅限定同字段内的两个值）

| 描述符 | 含义 |
|--------|------|
| `#` | 两词同句 |
| `%` | 两词同句且前者在前 |
| `/NEAR N` | 同句且相隔不超过 N 个字词 |
| `/PREV N` | 前者在前且间隔不超过 N |
| `/SEN N` | 同段且句子序号差不大于 N |
| `/PRG N` | 相隔不超过 N 段 |
| `$ N` | 检索词最少出现 N 次 |

检索值与运算符须用**一组英文半角单引号**括起：

```
FT = '人工智能 # 推荐算法'
FT = '人工智能 /NEAR 10 推荐算法'
FT = '出版 /PRG 5 法规'
FT = '大数据 $5'
```

`/AFT N` 在官方手册中定义与示例互相矛盾，**暂不推荐使用**。

## 7. 可直接复用的组合示例

```
# 概念组 + 同义词扩展（块内或、块间与）
SU %= ('生成式AI+生成式人工智能+AIGC') AND SU %= ('广告+营销')

# 主题 + 特定作者
SU %= 知识管理 AND AU = 邱均平

# 限定年份与核心概念
SU %= 信息茧房 AND YE BETWEEN ('2020', '2024')

# 篇名精确 + 摘要模糊 + 排除
TI = 算法推荐 AND AB % 青少年 NOT TI = 综述
```

## 8. 使用注意

1. 表达式必须**单行**，不能带换行。
2. 括号、单引号必须成对，且使用英文半角。
3. 位置描述符只用于同一字段内的两个值，不能连接多个值。
4. 专业检索**不支持**在一框式检索框里直接粘贴；它属于高级检索页的独立标签。
5. 本项目的 `--professional` 会校验括号与引号配对、字段代码存在性，
   但**不做语法改写**，语义由知网判定。

## 9. 手册存疑三处（不得当作确定事实引用）

1. 字段表写 `SN=ISSN`，匹配运算符适用字段里有一处写作 `ISSN`。
2. 逻辑示例使用了 `TKA`（篇关摘），但 `TKA` 未出现在前版字段代码表中。
3. `/AFT N` 定义写"超过 N 个字词"，示例解释却是"间隔不超过 N 个字词"。

需要用到这三处时，先在知网页面手工验证再采用。
