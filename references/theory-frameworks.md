# 人文社科常用理论框架库

> `theory-catalog` / `theory-match` 的数据底稿（人工查阅版）。脚本内置同源数据在 `scripts/core/theory_catalog.py`。
> 本库为**常用理论精选**（非穷举）；理论是否适配某研究是学术判断，由研究者与 Agent 据研究问题、文献、导师意见决定，脚本只给有依据的备选清单。
> 用户可用 `--library custom.json`（list 或 `{theories:[...]}`，同 id 覆盖）叠加自定义条目。

## 字段说明

每条理论含：`id`、`name`（理论名）、`proposer`（提出者）、`discipline`（学科）、`concepts`（核心概念）、`keywords`（检索关键词）、`summary`（一句话简介）、`key_refs`（代表文献提示）。

## 学科枚举

社会学、政治学、传播学、教育学、管理学、经济学、心理学、人类学、法学、哲学。

## 理论一览

### 社会学
- **社会资本理论**（布迪厄/科尔曼/帕特南）：社会关系网络中的资源，强调信任与互惠对集体行动的促进。核心：社会网络、信任、互惠、公民参与。
- **弱关系/嵌入性理论**（格兰诺维特）：弱关系在信息与机会获取中常比强关系有效；经济行为嵌入社会网络。核心：弱关系、结构洞、嵌入性。
- **场域-惯习理论**（布迪厄）：场域、惯习与各类资本共同塑造实践与社会区隔。核心：场域、惯习、文化资本、符号暴力。
- **结构化理论**（吉登斯）：结构既是行动的中介也是结果（结构二重性）。核心：结构二重性、能动性、规则与资源。
- **风险社会理论**（贝克）：现代化制造系统性风险，进入自反性现代化。核心：风险社会、自反性、个体化。
- **标签理论**（贝克尔/莱默特）：越轨是社会施加标签的结果，标签催生次级越轨。核心：越轨、污名、标签。
- **社会建构主义**（伯格/卢克曼）：现实与知识经社会互动被建构并制度化。核心：社会建构、知识社会学、制度化。
- **实践理论**（布迪厄/夏茨基）：聚焦日常实践的逻辑与惯例。核心：实践、惯例、身体技术。

### 政治学
- **新制度主义**（迪马吉奥/鲍威尔/诺斯）：制度塑造组织与行为，组织趋于同形，变迁具路径依赖。核心：制度同形、路径依赖。
- **多源流理论**（金登）：问题、政策、政治三流在政策之窗耦合。核心：政策之窗、议程设置、政策企业家。
- **倡议联盟框架**（萨巴蒂尔）：不同信念体系的倡议联盟竞争，变迁源于学习与外部冲击。核心：倡议联盟、信念体系、政策学习。
- **治理理论**（罗茨/罗西瑙）：公共事务由多元主体网络协同处理。核心：多中心治理、网络治理。

### 传播学
- **议程设置理论**（麦库姆斯/肖）：媒介报道强度影响公众认为哪些议题重要。核心：议程设置、属性议程、媒介显著性。
- **框架理论**（戈夫曼/恩特曼）：传播通过选择与凸显建构意义框架。核心：框架、框架化、凸显与遮蔽。
- **使用与满足理论**（卡茨/布卢姆勒）：受众主动选择媒介满足需求。核心：主动受众、媒介需求、满足。
- **沉默的螺旋**（诺依曼）：惧怕孤立使少数意见者趋于沉默。核心：意见气候、从众、孤立恐惧。

### 教育学 / 心理学
- **建构主义学习理论**（皮亚杰/维果茨基）：学习是主动建构，社会互动与支架促进发展。核心：最近发展区、同化顺应、支架。
- **自我决定理论**（德西/瑞安）：满足自主、胜任、归属增强内在动机。核心：自主、胜任、归属、内在动机。
- **计划行为理论**（阿杰恩）：态度、主观规范、知觉行为控制决定行为意向。核心：行为意向、主观规范、行为控制。
- **社会认知理论**（班杜拉）：观察学习与自我效能，在三元交互中能动行动。核心：自我效能、观察学习、三元交互。

### 管理学
- **资源基础观**（巴尼/沃纳菲尔特）：持续竞争优势源于 VRIN 异质性资源。核心：VRIN资源、持续竞争优势。
- **动态能力理论**（蒂斯）：感知、捕获、重构以适应变化。核心：感知、捕获、重构。
- **利益相关者理论**（弗里曼）：平衡各利益相关者诉求。核心：利益相关者、利益平衡、企业责任。
- **技术接受模型**（戴维斯）：感知有用性与易用性决定技术接受。核心：感知有用性、感知易用性、使用意向。

### 经济学
- **委托代理理论**（詹森/麦克林）：信息不对称引发道德风险，需激励相容契约。核心：信息不对称、道德风险、激励相容。
- **交易成本理论**（科斯/威廉姆森）：交易成本决定市场还是科层。核心：交易成本、资产专用性、纵向一体化。
- **理性选择理论**（奥尔森/科尔曼）：约束下追求效用最大化，集体行动有搭便车困境。核心：效用最大化、集体行动、搭便车。

### 人类学 / 法学
- **深描/解释人类学**（格尔茨）：文化是意义之网，应深描解释地方性意义。核心：深描、文化解释、地方性知识。
- **礼物交换理论**（莫斯）：礼物含给予、接受、回报三重义务的总体性社会事实。核心：互惠、义务、总体性呈现。
- **法律多元主义**（格里菲斯/摩尔）：国家法与多种非国家规范秩序并存。核心：法律多元、半自治社会场域、民间法。

## 使用提示

- 先用 `theory-match --keywords` 据研究问题关键词缩小候选，再用 `theory-catalog --discipline` 浏览学科全貌。
- 匹配得分仅是关键词重叠，不代表理论适配度；务必回到原典与本领域文献核对再决定。
- 多数研究用 1 个主理论 + 0-2 个补充视角；避免理论堆砌。
