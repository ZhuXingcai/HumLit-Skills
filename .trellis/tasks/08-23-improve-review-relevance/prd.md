# P1：改进 review 检索相关性与主题词清洗

## Goal

减少 OpenAlex 本体标签和跨领域高被引论文对 `review/topics/write` 的污染，使推荐精读、主题聚类和写作分支更接近研究者给定的问题，而不是把 `generative grammar`、`dynamics (music)` 等元数据噪声当作学术主题。

## Evidence

端到端验证的宽检索库与精选库均出现主题标签噪声；部分题名和摘要高度相关的文献被统一标为 `low_relevance`。

## Requirements

- 建立包含相关文献、跨领域误召回和 OpenAlex 本体噪声词的合成 fixture。
- 区分“检索候选池”和“可进入综述语料”的门槛与原因。
- 相关性优先使用题名、摘要和用户主题词，降低通用 ontology keyword 的主导作用。
- 聚类标签应可解释，并保留原始元数据供审计。
- 分数仍只用于筛选/精读顺序，不得升级为论文质量判断。

## Acceptance Criteria

- [ ] 已知噪声词不再成为主要聚类标题。
- [ ] 精确题名/摘要相关文献不再被全部判为低相关。
- [ ] 过滤与降权规则有单元测试和 E2E 测试。
- [ ] 完整质量门禁通过，现有多学科检索不发生明显回归。

## Out of Scope

- 引入向量数据库或外部付费 reranker。
- 自动宣称研究空白或学术质量。
- Zotero 适配。
